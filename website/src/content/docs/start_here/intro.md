Scalable and efficient data packing

See [code samples](https://github.com/google/sedpack/tree/main/docs).

The code is a major refactor of the data saving and loading code from the
[SCAAML](https://github.com/google/scaaml) project.

Using an AI coding assistant or LLM agent? Sedpack ships with a bundled
`SKILL.md` for the high-level `sedpack.io` API and a repository
[`AGENTS.md`](https://github.com/google/sedpack/blob/main/AGENTS.md) for
contributors—see the
[Installation guide](/sedpack/start_here/install/#ai-agents-and-llm-skills) for
setup instructions.
